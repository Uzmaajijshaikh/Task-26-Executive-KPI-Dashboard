Data Analytics Internship – Task 26 (Executive KPI Dashboard)

This repository contains my submission for Task 26 of the Data Analytics Internship.

Dataset - Sample Superstore Dataset

Objective - The objective was to create a one-page executive dashboard with key business KPIs, dynamic filters, and clear visualizations for sales and profit analysis.

Tools Used
1. Power BI
2. Sample-Superstore Dataset
3. GitHub

Executive KPI Dashboard
1. Imported the Sample Superstore dataset into Power BI.
2. Created KPI cards for Total Sales, Total Profit, Total Orders, and Profit Margin.
3. Used Distinct Count of Order ID to calculate the total number of unique orders.
4. Created slicers for Region, Category, and Segment to allow dynamic filtering.
5. Created a column chart showing Sales by Category.
6. Created a column chart comparing Sales and Profit by Region.
7. Created a line chart showing the monthly sales trend.
8. Added KPI definitions to explain the meaning of each metric.
9. Tested the slicers to ensure that the dashboard visuals and KPIs update dynamically.
10. Designed the dashboard as a single-page management view to keep the analysis concise and easy to understand.

KPI Definitions
1. Total Sales – Total revenue generated from all sales.
2. Total Profit – Total profit generated from the sales.
3. Total Orders – Number of unique orders placed.
4. Profit Margin – Percentage of sales retained as profit.

Files
1. Task 26.pbix - Power BI executive KPI dashboard
2. README.md - Summary of the dashboard and analysis

Conclusion
The executive KPI dashboard was successfully created using Power BI. It provides a concise view of sales, profit, orders, and profit margin while allowing users to explore the data using dynamic filters for Region, Category, and Segment.
